GELTION — landing page

Открыть локально:
  1) Самый простой способ: открой geltion-standalone.html двойным кликом
     (всё в одном файле — картинка/стили/скрипты внутри).
  2) Или открой index.html (рядом должны лежать папки css/, js/, assets/).

Структура:
  index.html              — разметка
  css/style.css           — стили (полный layout: меню слева, рейл справа, сцена по центру)
  js/main.js              — пыль, дропдаун региона, счётчик, тосты
  assets/scene.webp       — фон-сцена (подземелье, герой)
  assets/scene-alt.webp   — запасной вариант сцены
  geltion-standalone.html — всё в одном файле для быстрого просмотра
